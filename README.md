# 数学小课堂 · 二年级班级管理

这是一个面向小学二年级数学教学场景的单页 Web 应用，帮助教师快速管理学生信息、记录作业等级、统计考试成绩以及跟踪班级积分表现。该项目使用纯前端实现，适合课堂教学辅助、数据可视化展示和教学成果管理。

## 项目简介

本项目主要用于：

- 管理班级学生档案
- 记录作业表现并按 A+ / A / A- / B / C 等级进行评价
- 统计考试分数与班级平均分
- 记录学生积分获取与消费情况
- 通过图表查看班级和学生的学习趋势

界面风格采用清新、温暖的教学风格，适合课堂管理和教师展示。

## 功能特点

### 1. 班级仪表盘
- 查看班级学生总数
- 查看作业平均等级
- 查看考试平均分
- 查看累计积分总量
- 查看班级成绩趋势图和近期动态

### 2. 学生管理
- 添加、编辑、删除学生
- 查看学生个人详情
- 查看学生作业等级、考试均分、积分余额
- 进入学生详情页查看个人成长趋势

### 3. 作业管理
- 新建作业记录
- 以等级制记录每位学生作业表现
- 支持等级：A+、A、A-、B、C
- 统计平均等级和各等级分布

### 4. 考试管理
- 新建考试记录
- 记录每位学生分数
- 查看考试平均分、最高分、最低分

### 5. 积分管理
- 记录学生积分奖励和消费
- 查看积分余额、积分原因和分类记录

### 6. 数据分析图表
- 学生个体作业等级变化趋势
- 学生个人考试分数变化
- 班级作业平均趋势
- 班级考试平均趋势
- 学生积分累计变化

## 运行方式

### 方式一：直接打开

1. 进入项目目录
2. 双击打开 `index.html`
3. 在浏览器中查看并使用该应用

### 方式二：本地服务器

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 数据说明

该应用没有后端数据库，数据默认保存在浏览器的 `localStorage` 中。这样便于本地演示和单机教学管理场景使用。

注意：

- 清除浏览器缓存/存储后，数据可能丢失
- 适合本地演示与教学场景，不适合作为生产级多用户系统
